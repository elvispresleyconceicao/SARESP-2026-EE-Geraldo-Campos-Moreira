# SARESP 2026 | EE Geraldo Campos Moreira

Portal de acesso às avaliações e aos simulados escolares da **Escola Estadual Professor Doutor Geraldo Campos Moreira**, com organização dos formulários por ano escolar.

## Objetivo

Facilitar o acesso dos estudantes aos formulários de avaliação, reunindo os links em uma página única, simples, responsiva e acessível por computadores, tablets e celulares.

## Turmas atendidas

* **6º ano:** formulário de avaliação do 6º ano.
* **7º ano:** formulário de avaliação do 7º ano.
* **8º ano:** formulário de avaliação do 8º ano.
* **9º ano:** formulário de avaliação do 9º ano.

## Tecnologias utilizadas

* HTML5
* CSS3
* Google Forms
* GitHub Pages

## Estrutura do projeto

```text
SARESP-2026-EE-Geraldo-Campos-Moreira/
└── index.html
```

O arquivo `index.html` contém a estrutura da página e os estilos CSS incorporados, sem necessidade de arquivos adicionais para o funcionamento básico do portal.

## Publicação

O site pode ser hospedado gratuitamente pelo GitHub Pages.

Para ativar a publicação:

1. Acesse **Settings** no repositório.
2. Entre em **Pages**.
3. Selecione **Deploy from a branch**.
4. Escolha a branch `main` e a pasta `/ (root)`.
5. Clique em **Save**.

Após a publicação, o GitHub fornecerá o endereço do site.

## Orientações aos estudantes

1. Selecione o ano escolar correspondente à sua turma.
2. Abra o formulário indicado.
3. Leia as instruções e preencha os dados solicitados.
4. Em caso de dificuldade técnica, procure a equipe escolar.
